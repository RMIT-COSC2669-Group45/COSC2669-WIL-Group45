# Raw Source Documents

This folder contains original, unchanged copies of the official Victorian tenancy sources used to prepare the cleaned knowledge-base documents.

Each raw document should have a corresponding cleaned Markdown file in `data/cleaned/`.

## Format:

- Raw source: `cav_<topic>_001.pdf`
- Cleaned source: `cav_<topic>_001.md`

## Naming example

- Raw source: `cav_repairs_001.pdf`
- Cleaned source: `cav_repairs_001.md`

The original content should not be edited after collection.
